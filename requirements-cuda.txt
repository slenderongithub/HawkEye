#
#   RTX 50-series (5060/5070/5080/5090, Blackwell / sm_120)  ->  cu128, torch>=2.7
#     pip install "torch>=2.7" torchvision --index-url https://download.pytorch.org/whl/cu128
#
#   RTX 40/30-series (Ada / Ampere)                          ->  cu124 is fine
#     pip install "torch>=2.4" torchvision --index-url https://download.pytorch.org/whl/cu124
#
#   Blackwell is NOT optional here: wheels older than cu128 ship no sm_120 kernels,
#   so a 5060 fails at the first conv with
#     "CUDA error: no kernel image is available for execution on the device"
#   torch.cuda.is_available() still returns True in that state — it is not a check
#   that the wheel actually matches the card. Verify with the smoke test in
#   docs/training.md §0.6 (it runs a real op, not just is_available()).
#
